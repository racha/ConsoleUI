# Contributing to ConsoleUI

Player guide and developer docs: [racha.github.io/ConsoleUI](https://racha.github.io/ConsoleUI/).

Start here:

- [Developer overview](https://racha.github.io/ConsoleUI/development/overview/)
- [Public API](https://racha.github.io/ConsoleUI/development/api/)
- [Cursor integrations](https://racha.github.io/ConsoleUI/development/cursor-integrations/)
- [Visual language](https://racha.github.io/ConsoleUI/development/visual-language/)
- [Testing and releases](https://racha.github.io/ConsoleUI/development/testing-releases/)

Target is original WoW 1.12 (Lua 5.0). Do not import Retail or modern Classic APIs. Do not wrap movement or click-look globals.

Issues: include client, mapper/layout, steps, first error, and `/cui test`. Redact names and paths.
