| Environment | Status |
| --- | --- |
| OctoWoW original 1.12 | Primary tested client |
| TurtleWoW original 1.12 | Supported where the client matches Vanilla behavior |
| RavenCraft / Capybara Paradise 1.12 | Intended; verify server-specific differences |
| Retail, modern Classic Era, Wrath, Cataclysm | Unsupported |

[Interact]({{ site.data.project.interact }}) is a separate recommended client mod. Steam Input, WoWpadX, and other mappers sit outside ConsoleUI. Their exact versions need their own check.

Optional addon deps listed in the TOC (pfUI, Quiver, SimpleActionSets, ModernMapMarkers) are compatibility hooks, not requirements. To hook your own frames into the virtual cursor, see [Cursor integrations]({{ '/development/cursor-integrations/' | relative_url }}).
