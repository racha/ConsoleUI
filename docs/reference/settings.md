`/cui` and `/consoleui` open settings. The sidebar order is:

| Page | Owns |
| --- | --- |
| General | Controller icons, language, keyboard behavior, general UI |
| Mouse | Mouse Look, lock/unlock groups, invert, speed |
| Action Bars | Layouts, main/touch/stance/pet bars, positions and scales |
| HUD | XP, reputation, cast, loot, hint bar |
| Bindings | Base and modifier pages, spell placement, touch and mouse actions |
| Rings | User Ring creation and editing |
| Frames | Minimap, auras, player, target, party, party pets |
| Profiles | This character and Copy From |
| About | Version, [credits]({{ '/reference/credits/' | relative_url }}), project links |

Debug stays off the normal sidebar. Use `/cui test` and `/cui debug` when you need a report.

Every feature page explains its own controls. This table is the index.
