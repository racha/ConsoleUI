## Everyday

| Command | Purpose |
| --- | --- |
| `/cui` or `/consoleui` | Open settings |
| `/cui look` | Toggle Mouse Look |
| `/cui help` | Print the command list |
| `/cuik` | Keyboard status |
| `/cuik on` / `off` | Enable or disable the keyboard |
| `/cuik check` | Keyboard self-check |

## Support

| Command | Purpose |
| --- | --- |
| `/cui test` or `/cui audit` | Run the in-game audit |
| `/cui debug` | Print a diagnostics report |
| `/cui debug on` / `off` | Extra debug messages |

## Setup shortcuts

| Command | Purpose |
| --- | --- |
| `/cui modern` / `classic` | Action-bar appearance |
| `/cui gold` / `gold off` | Action-bar gold border |
| `/cuihealer` `[on\|off\|toggle]` | Healer mode |
| `/cuiignore add <pattern>` | Ignore a cursor frame pattern |
| `/cuiignore remove <number or pattern>` | Remove a pattern |
| `/cuiignore list` | List custom patterns |
| `/cuiignore test <frame name>` | Test a frame name |

`/cuiprofile`, `/cuiframe`, and `/cuirank` exist for profile, frame, and autorank helpers. Prefer the `/cui` pages unless a support reply asks for the slash form.
