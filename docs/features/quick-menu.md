The Quick Menu is the built-in gold wheel. It is not a user Ring and it is not cursor navigation.

## How to use it

1. Bind **Toggle Radial Menu** in `/cui` → Bindings or WoW Key Bindings.
2. Hold the bind.
3. Steer with the left stick or WASD. The eight slices sit at the compass points, starting at the top.
4. Press A to open the highlighted slice.
5. Press B to close.

Center cluster, from the face buttons:

| Button | Action |
| --- | --- |
| Y | Game Menu |
| X | Reload UI |
| A | Confirm the selected slice |
| B | Back / close |

## Limitations

- The menu steals WASD while it is open, then restores movement. If walk dies after close, see [Troubleshooting]({{ '/reference/troubleshooting/' | relative_url }}).
- Both Turn and Strafe A/D bindings work.
- Do not bind the menu to a key you still need for a Ring at the same time.

Custom spell and item wheels are [Rings]({{ '/features/rings/' | relative_url }}).
