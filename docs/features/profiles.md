ConsoleUI creates one automatic, undeletable profile for the current character. Named account-wide profiles are not part of V1.

The profile stores settings, positions, scales, bindings, Rings, touch assignments, action bars, and keyboard configuration. The keyboard dictionary stays account-wide and is not copied.

## Copy From

Open `/cui` → **Profiles**. The page names this character, then offers Copy From for other characters and imported legacy templates.

Copy is rejected in combat. A different-class copy warns first. Unresolved spells, macros, or items stay on the destination slot and are reported.

Existing RC6 data is migrated; current settings are not erased to make the new store.
