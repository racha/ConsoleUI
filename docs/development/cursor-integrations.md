The virtual cursor scans **Buttons**, **CheckButtons**, **EditBoxes**, and **Sliders** under a hooked frame. It skips unnamed frames, disabled buttons, and any **frame name** that matches an ignore pattern.

Two ignore lists run on every scan:

1. **Built-in** — `ConsoleUI.cursor.buttonsToIgnore` inside `cursor/cursor.lua`. Ships with the addon. Updates overwrite it. Do not edit this file to keep personal ignores.
2. **Custom** — `ConsoleUIProfileDB.cursorIgnorePatterns` in account SavedVariables. This is what `/cuiignore`, `ConsoleUI_AddCursorIgnorePattern`, and a WTF edit all write.

Names are matched with Lua `string.find(buttonName, pattern)` — **Lua patterns**, not PCRE.

## Built-in ignore list

This is the current shipped table. Copy the style. Do not patch it in `AddOns` if you want the ignore to survive an update — put the same kind of pattern in the custom WTF list instead.

```lua
Cursor.buttonsToIgnore = {
    "[A-Za-z0-9]+MoneyFrameGoldButton",
    "[A-Za-z0-9]+MoneyFrameSilverButton",
    "[A-Za-z0-9]+MoneyFrameCopperButton",
    "FriendsDropDownButton",
    "TabardFrameMoneyFrame.*",
    -- Bagshui: ignore money buttons, group headers, and utility buttons
    "BagshuiBagsMoney.*Button",
    "BagshuiBankMoney.*Button",
    "BagshuiBagsbuttonShowBagBar",
    "BagshuiBankbuttonShowBagBar",
    "BagshuiBagsGroup%d+",
    "BagshuiBankGroup%d+",
    -- Generic Bagshui patterns (catch-all for similar frames)
    "Bagshui.*Group%d+",
    "Bagshui.*buttonShow.*",
}
```

| Pattern | What it skips |
| --- | --- |
| `[A-Za-z0-9]+MoneyFrameGoldButton` | Coin buttons on any `SomethingMoneyFrame` |
| `TabardFrameMoneyFrame.*` | Everything under the tabard money frame |
| `BagshuiBagsGroup%d+` | Bagshui bag group headers (`Group1`, `Group2`, …) |
| `Bagshui.*buttonShow.*` | Bagshui “show bag bar” utilities |

`%d+` is one or more digits. `.*` is “anything.” `%` is the Lua escape (`%d`, `%s`, `%.`).

Unnamed buttons cannot be ignored. Name the frame: `CreateFrame("Button", "MyAddonClose", parent)`.

## Custom ignores — three ways, one store

All three write **`ConsoleUIProfileDB.cursorIgnorePatterns`**. Account-wide. Not copied by Profiles → Copy From. Max **100** patterns. Max **200** characters. Duplicates of a built-in or existing custom pattern are rejected. Invalid Lua patterns are rejected.

### 1. In-game slash

```text
/cuiignore add Bagshui.*Group%d+
/cuiignore add MyAddonDecor
/cuiignore list
/cuiignore test BagshuiBagsGroup3
/cuiignore remove 1
/cuiignore remove MyAddonDecor
```

`/ceignore` is the same command. `test` prints whether that **name** will be skipped (built-in or custom).

### 2. Lua from your addon

```lua
-- PLAYER_ENTERING_WORLD is safe. Guard the global.
local ok, result = ConsoleUI_AddCursorIgnorePattern("MyAddonGoldButton")
if not ok then
    DEFAULT_CHAT_FRAME:AddMessage("ConsoleUI ignore: " .. tostring(result))
end

ConsoleUI_RemoveCursorIgnorePattern("MyAddonGoldButton")
-- or by 1-based index:
ConsoleUI_RemoveCursorIgnorePattern(1)
```

| Function | Returns |
| --- | --- |
| `ConsoleUI_AddCursorIgnorePattern(pattern)` | `true, cleaned` or `false, error` |
| `ConsoleUI_RemoveCursorIgnorePattern(patternOrIndex)` | `true, removed` or `false, error` |

### 3. Edit the WTF file (no slash, no addon)

This is the same table `/cuiignore add` writes. Use it to seed a machine, copy ignores between PCs, or add patterns while the game is closed.

**Quit the client first.** If you edit this file while logged in, logout overwrites your edits.

Account-wide file (this is the correct one):

```text
WTF/Account/<ACCOUNT>/SavedVariables/ConsoleUI.lua
```

`<ACCOUNT>` is the Battle.net / login account folder Steam or the launcher created. It is **not** `WTF/Account/<ACCOUNT>/<Realm>/<Character>/SavedVariables/ConsoleUI.lua`. That character file is `ConsoleUIDB` and does **not** hold cursor ignores.

WoW writes the custom list as a 1-based array:

```lua
ConsoleUIProfileDB = {
    ["schemaVersion"] = 2,
    ["cursorIgnorePatterns"] = {
        [1] = "MyAddonDecor",
        [2] = "MyAddonTab%d+Chrome",
        [3] = "Bagshui.*Group%d+",
    },
    ["characters"] = {
        -- profiles live here; do not put ignores inside a character table
    },
}
```

You can also write a fresh file that only sets the ignore table if you are seeding. Keep `schemaVersion` and `characters` if they already exist — delete those tables and Copy From / settings vanish.

**Example — add two patterns by hand**

1. Quit WoW.
2. Open `WTF/Account/<ACCOUNT>/SavedVariables/ConsoleUI.lua` in a text editor.
3. Find `["cursorIgnorePatterns"]`. If it is missing, add the block next to the other `ConsoleUIProfileDB` keys.
4. Add rows. Use the next free index. Do not reuse a built-in pattern string.

```lua
["cursorIgnorePatterns"] = {
    [1] = "[A-Za-z0-9]+VendorTipButton",
    [2] = "MyBagsHeader%d+",
    [3] = "MyBagsbuttonShow.*",
},
```

5. Save as UTF-8 without a BOM. Lua 5.0 table syntax only — no `#`, no trailing commas after the last entry if your editor adds them in a way that breaks 5.0 (a trailing comma on the last field is fine in 5.0; a trailing comma after the last *table* close is not a thing).
6. Start the client. `/cuiignore list` should print your rows. `/cuiignore test MyBagsHeader2` should say it will be ignored.

**Copy ignores to another PC**

Copy only the `cursorIgnorePatterns` table between two `ConsoleUI.lua` account SavedVariables files. Do not copy the whole `characters` tree unless you intend to replace every character profile.

## Hook your window so the cursor appears

ConsoleUI wraps `OnShow` / `OnHide` on bags, vendors, spellbook, `/cui`, pfUI / Bagshui / Bagnon, and others. Your frame is invisible to the cursor until hooked.

```lua
local boot = CreateFrame("Frame")
boot:RegisterEvent("PLAYER_ENTERING_WORLD")
boot:SetScript("OnEvent", function()
    if not ConsoleUI or not ConsoleUI.hooks then
        return
    end
    if MyAddonFrame then
        ConsoleUI.hooks:HookDynamicFrame(MyAddonFrame, "My Addon")
    else
        ConsoleUI.hooks:TryHookNamedFrame("MyAddonFrame", "My Addon")
    end
end)
```

| Method | When |
| --- | --- |
| `HookDynamicFrame(frame, label)` | You have the frame. Hooks once (`ceHooked`). Starts the cursor if it is already shown. |
| `TryHookNamedFrame("Name", label)` | `getglobal`; no-op if missing. Safe to call again. |
| `RestoreFrameScripts(frame)` | Undo. Rare. |

Original `OnShow` / `OnHide` run first. Do not replace those scripts after hooking.

Requirements: `GetScript` / `SetScript`, named interactive children, a real `GetCenter()`. Pin widgets with `SetPoint` — 1.12 `GetCenter` can lie.

## What the cursor clicks

`Cursor:IsInteractiveElement` is true for enabled `Button` / `CheckButton`, any `EditBox`, any `Slider`, and player/party/raid frames only when healer mode is on. A Select is `ConsoleUI_ClickCursor("LeftButton")`. It does not set `IsMouseButtonDown(1)`.

## Minimal integration addon

```text
## Interface: 11200
## Title: MyAddon ConsoleUI
## RequiredDeps: ConsoleUI

MyAddon_ConsoleUI.lua
```

```lua
local f = CreateFrame("Frame")
f:RegisterEvent("PLAYER_ENTERING_WORLD")
f:SetScript("OnEvent", function()
    if ConsoleUI_AddCursorIgnorePattern then
        ConsoleUI_AddCursorIgnorePattern("MyAddonGoldButton")
        ConsoleUI_AddCursorIgnorePattern("MyAddonTab%d+Decor")
    end
    if ConsoleUI and ConsoleUI.hooks and MyAddonMainFrame then
        ConsoleUI.hooks:HookDynamicFrame(MyAddonMainFrame, "My Addon")
    end
end)
```

Or skip the addon and put those same strings in `WTF/Account/<ACCOUNT>/SavedVariables/ConsoleUI.lua` as shown above.

## Already hooked

pfUI bags/bank, Bagshui, Bagnon / Banknon. Prefer a pull request over a second wrap. TOC `OptionalDeps` (`pfUI`, `Quiver`, `SimpleActionSets`, `ModernMapMarkers`) are load-order only.

## Do not

- Edit `buttonsToIgnore` in a live `AddOns/ConsoleUI` install for personal ignores. Use WTF or the API.
- Edit WTF while the client is running.
- Put `cursorIgnorePatterns` on `ConsoleUIDB` (character file). The cursor does not read that table.
- Hook `WorldFrame`.
- Call `MouselookStart` to “help.”
- Wrap `MoveForwardStart`, jump, or click-look globals.
